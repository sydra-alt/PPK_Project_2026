# JARA — An Advanced Todo List

Aplikasi web untuk mengelola tugas pribadi maupun tim. Pengguna dapat membuat, mengelompokkan, dan mengatur tugas ke dalam beberapa list/project, menetapkan prioritas dan tenggat waktu, menandai tugas sebagai selesai, serta berkolaborasi dengan pengguna lain dalam list/project.

## User Story

Sebagai pengguna, saya ingin mengelola tugas pribadi maupun tugas bersama dalam beberapa list/project, sehingga saya dapat mengatur, mengerjakan, dan memantau tugas dengan lebih terorganisir.

## Daftar SRS

| **Kode** | **Deskripsi** | **Acceptance Criteria** |
|---|---|---|
| SRS-001 | Manajemen akun pengguna | - Pengguna memiliki akun untuk mengakses aplikasi<br>- Akun dapat digunakan untuk mengakses fitur aplikasi |
| SRS-002 | Membuat list/project | - Pengguna dapat membuat beberapa list/project<br>- List/project dapat digunakan untuk mengelompokkan tugas |
| SRS-003 | Mengelola list/project | - Pengguna dapat mengatur list/project yang dimilikinya |
| SRS-004 | Membuat tugas | - Pengguna dapat membuat tugas<br>- Tugas dapat dimasukkan ke dalam list/project tertentu |
| SRS-005 | Mengatur prioritas tugas | - Pengguna dapat menetapkan prioritas pada suatu tugas |
| SRS-006 | Mengatur tenggat waktu tugas | - Pengguna dapat menetapkan deadline/tenggat waktu pada tugas |
| SRS-007 | Menandai tugas selesai | - Pengguna dapat mengubah status tugas menjadi selesai |
| SRS-008 | Kolaborasi dalam list/project | - Pemilik list/project dapat menambahkan pengguna lain ke dalam list/project |
| SRS-009 | Mengelola tugas bersama | - Pengguna yang ditambahkan ke list/project dapat mengerjakan tugas dalam list tersebut |
| SRS-010 | Memantau progres list/project | - Pemilik list/project dapat melihat progres penyelesaian tugas dalam list tersebut |
| SRS-011 | Manajemen akun oleh admin | - Admin dapat menambah akun pengguna<br>- Admin dapat menghapus akun pengguna |
